# Kovrell

Kovrell calls the vendor before you pay.

AI voice callback control for vendor bank-detail change requests, built on the AssemblyAI Voice Agent API.

## Run locally

```bash
npm install
cp .env.example .env.local   # add ASSEMBLYAI_API_KEY
npm run dev
```
